
# 📊 Google Photos Search & Memory Study: Executive Summary

> **Headline Insight:** Users don't need more metadata filters; they need an interface that understands "vibes" and context. The biggest barrier isn't that photos are lost, but that human memory works associatively (visuals, timeframes) while current search requires exact, literal keywords.

### 📈 Key Metrics
*   **The Translation Gap:** 60% of failures occur because users "couldn't summarize what I remembered into simple search terms."
*   **The Time Tax:** When searches succeed, they still take 5–15 minutes of tedious scrolling or query tweaking.
*   **The Drop-off:** "Scroll or give up" is the dominant workaround, indicating a massive abandonment rate for memory retrieval.

### 🗂️ First Instincts (What users try first)
1.  Type descriptive keywords (55%)
2.  Scroll timeline endlessly (45%)

### ❌ Top Failure Reasons
1.  Couldn't summarize memory into search terms (60%)
2.  App misunderstood the query literally (30%)
3.  Search returned zero results (10%)

*(Note: Percentages above are directional based on the simulated dataset distribution).*

### 🗣️ Five Patterns from Interviews
1.  **First Action:** Users default to typing multi-word phrases ("blue slide conference") expecting AI comprehension, but get literal keyword matches instead.
2.  **Biggest Failure:** The "Vocabulary Mismatch" – users remember *what* a photo is about, but search engines only know *what objects* are in the photo.
3.  **What They Remember:** Broad timeframes, colors, and associated life events ("around my birthday") are recalled far more often than exact locations or dates.
4.  **Workaround:** Brute-force scrolling or completely abandoning the search out of frustration.
5.  **What Would Build Trust:** Explainability (the AI explaining *why* it retrieved a specific photo) and interactive narrowing (step-by-step filtering rather than a single search bar).

### 🎯 Jobs To Be Done (JTBD)
*   **JTBD 1:** "When I vaguely remember an associated detail of a past event (like the color of a table), I want the search engine to understand that contextual clue, so that I don't have to scroll through thousands of photos to find a specific document."
*   **JTBD 2:** "When I am looking for a specific photo among hundreds of similar ones (like my dog as a puppy), I want to be able to use natural language modifiers, so that I can pinpoint the exact memory instantly."

*n = 45 (5 real + 40 simulated); 5 simulated interviews. Directional only.*
